# Лабораторная работа №4 — C# WinForms

## Требования
- Visual Studio 2022 (Community достаточно)
- .NET 8 SDK
- Windows 10/11

## Запуск
1. Откройте `Lab4SortingApp.sln`.
2. `Build → Build Solution` (Ctrl+Shift+B).
3. `Debug → Start Debugging` (F5).

## Проверка заданий

### Задание 1 — внутренняя сортировка
1. Вкладка «1. Внутренняя сортировка».
2. Нажмите «Сгенерировать массив» или введите свой.
3. Выберите алгоритм (SelectSort / BubbleSort / InsertSort / 
   ShellSort / HeapSort / QuickSort).
4. Поставьте задержку 100–300 мс и «Старт».
5. Наблюдайте: жёлтый/красный цвет — сравниваемые/переставляемые 
   элементы, лог внизу, счётчики сравнений/перестановок.

### Задание 2 — внешняя сортировка
1. Вкладка «2. Внешняя сортировка».
2. «Открыть файл» → выберите `Data/countries.csv` 
   (или `chemicals.csv`). Разделитель — `;`.
3. Выберите ключевой столбец (например, «Население» или 
   «Молекулярная_масса»).
4. Выберите метод: прямое / естественное / k-путевое слияние.
5. Поставьте задержку и «Старт». Лог покажет шаги слияния.
6. «Сохранить результат» — запишет отсортированную таблицу в файл.

### Задание 3 — слова, частоты, эксперимент
1. Вкладка «3. Слова + частоты + эксперимент».
2. «Загрузить .txt» → `Data/words.txt` или вставьте свой текст.
3. Выберите первый алгоритм (QuickSort / MergeSort / HeapSort) 
   и второй (RadixSort / ABC).
4. «Сортировать (оба алгоритма)» — покажет результаты, 
   проверит совпадение, выведет таблицу частот.
5. «Эксперимент (100…10000)» — замерит время обоих алгоритмов 
   на N = 100, 500, 1000, 2000, 5000, 10000 слов.
6. «Экспорт эксперимента в CSV» — сохранит таблицу.
7. График внизу показывает зависимость времени от N.

## Структура
- `Algorithms/` — все алгоритмы как генераторы `IEnumerable<SortStep>`
- `UI/` — по одной вкладке на задание
- `Data/` — тестовые CSV/TXT
